# بازار کسب‌وکار — Bazar Business

مخزن عمومی پروژه اندروید بازار کسب‌وکار (`ir.picamo.bazar`).

هدف: اتصال تولیدکنندگان، عمده‌فروشان، فروشندگان و مشتریان.

## ساخت نسخه اندروید

کد منبع نسخه 3.8.5 از بسته انتشار کنترل‌شده به این مخزن منتقل می‌شود. ساخت APK به‌صورت خودکار در GitHub Actions انجام خواهد شد. خروجی اولیه فقط **آزمایشی** است و برای انتشار، باید خارج از این مخزن با کلید اصلی خصوصی امضا شود.

**هشدار امنیتی:** هیچ توکن بله، رمز عبور، فایل `.jks` یا کلید امضای انتشار نباید در این مخزن عمومی قرار بگیرد.
