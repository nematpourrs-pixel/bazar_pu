# بازار کسب‌وکار ۳.۸.۶ – اصلاح دیده‌بان بازار

- حذف «نوبت‌های من» از میان‌برهای **صفحه خانه**، بدون حذف امکان مشاهده نوبت‌ها از حساب.
- جایگزینی متن آزمایشی «مورد ۱ تا ۵» با نرخ دلار، طلای ۱۸ عیار، سکه امامی، یورو، تتر، بیت‌کوین و اونس طلا.
- نمایش منبع، زمان به‌روزرسانی، واحد و وضعیت قیمت (به‌روز / قدیمی / ناموجود).
- سازگار با API پیشین `market.latest` و اصلاحیه جدید سرور ۶.۹.۶۶.
- عدم نمایش قیمت ساختگی وقتی نرخ واقعی در سرور وجود ندارد.

**مهم:** این شاخه سورس است، نه APK آماده انتشار. Build آزمایشی با GitHub Actions به‌تنهایی قابل انتشار در کافه‌بازار نیست؛ برای به‌روزرسانی روی نسخه قبلی باید APK با کلید خصوصی اصلی برنامه امضا شود. سرور همچنان باید جداگانه نصب و در شرایط واقعی آزمایش شود.
