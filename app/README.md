# بازار کسب‌وکار — اندروید ۳.۸.۱

شناسهٔ برنامه `ir.picamo.bazar` و versionCode برابر ۳۸۱ است. این سورس با سرور ۶.۹.۶۰ و وب‌اپ ۳.۲.۴ استفاده می‌شود.

در این نسخه، مسیر کسب‌وکارهای دنبال‌شده و دنبال‌کننده‌های هر کسب‌وکار اضافه شده، هدر حساب با رنگ اصلی هماهنگ شده و تصاویر از کش اختصاصی گوشی استفاده می‌کنند. بررسی مجوز گفتگو در اپ و ربات یکسان است. پنل وب سرور نیز جزئیات قابل کلیک درخواست‌ها و تنظیمات گفتگو را دارد.

نسخهٔ Node ۲۴، JDK ۱۷ کامل، Android SDK ۳۶، NDK 27.1.12297006، CMake 3.22.1 و Gradle 9.0.0 برای ساخت استفاده شده‌اند. نصب وابستگی‌ها با `npm ci` انجام می‌شود. اسکریپت postinstall سازگاری ابزار ساخت را با نسخه‌های قفل‌شده حفظ می‌کند.

```bash
npm ci
npm test -- --runInBand
npx tsc --noEmit
cd android
./gradlew assembleRelease -PreactNativeArchitectures=armeabi-v7a,arm64-v8a
```

کلید خصوصی انتشار در این سورس نیست. APK نهایی باید با کلید انتشار قبلی امضا شود. تنظیم مسیر SDK در `android/local.properties` محلی است و داخل ZIP سورس قرار ندارد.

خرید جدید پلن یا دسترسی ارتباطی در نسخهٔ بازار ارائه نشده؛ مجوز قبلی، حالت رایگان و دسترسی مدیر با تأیید سرور حفظ می‌شود. گفتگو در بله انجام می‌شود و پیام‌های پشتیبانی همچنان در اپ نیز نمایش داده می‌شوند.
